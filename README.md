One line of weather forecast, at most 140 characters, for a city that does
not exist — written to make a bored commuter smile at a rainy bus stop.

## Entry

> In Slantwell, rain falls sideways all morning, so the 8:15 bus arrives bone-dry while everyone waiting for it is soaked to the skin.

## Run

```sh
python3 main.py
```

`main.py` writes exactly one line to `MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `.` when the variable is unset). It is deterministic,
self-contained, and uses no network, clock, environment, or model calls.
